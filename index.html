BIOPHYSICAL CONTEXT & METHODOLOGY

The Research Question: Sparse Distance Reconstruction

IIT Mandi Research Focus

1. The Biophysical Challenge of Trajectory Sampling

Molecular dynamics (MD) simulations generate high-dimensional conformational ensembles capturing macromolecular thermal fluctuations. Characterizing conformational dynamics across thousands of atomistic coordinates is computationally intensive.

A central biophysical question is whether measuring a small subset of residue-pair distances is sufficient to reconstruct the broader distance matrix in an independent simulation run of the same protein under identical conditions.

2. Multi-Run Transfer vs In-Sample Overfitting

Selecting sensor measurements on a single simulation trajectory risks overfitting to transient local fluctuations and temporal autocorrelation. Such in-sample fits frequently fail when transferred to an independent simulation replicate.

CHARA evaluates transfer selection by using two development runs to select informative distances that minimize transfer prediction error onto an unseen third held-out run, measuring genuine out-of-run generalization.

Chara Trajectory Distance Reconstruction Pipeline

STAGE 1

Extract residue-pair distances from MD trajectories

Extracts pairwise inter-residue Cα distances dij(t) = ||ri(t) - rj(t)||2 with sequence separation |i - j| ≥ 3.

STAGE 2

Select informative measurements using two development runs

Applies greedy transfer search across two independent development runs to pick sensor distances, comparing M8 worst-direction and M7 mean-direction transfer.

STAGE 3

Fit a distance-reconstruction model on development data

Fits a multi-output ridge regression model Ŷ = (X - μx)W + μy, tuning shrinkage penalty λ across development runs.

STAGE 4

Evaluate reconstruction in a third, held-out run

Evaluates reconstruction on an independent third run using non-dimensional skill Skill = 1 - SSE / SSEbase relative to the development mean.

External Benchmark Systems & Pilot Scope

1. The 3 External Benchmark Systems

Evaluated on standardized atomistic MD trajectories from the ATLAS database (CHARMM36m, explicit TIP3P solvent, 100 ns triplicates):

  • • 1utg_A: Uteroglobin (all-α, 70 res, 1.34 Å)
  • • 2cg7_A: Fibronectin type III (all-β, 90 res, 1.20 Å)
  • • 2j6b_A: AFV1 viral protein (α+β, 109 res, 1.30 Å)
  • • 9 Held-Out Runs: 3 rotation folds per protein

2. Worst-Direction vs Average Transfer

M8 Robust Transfer selects sensor distances by minimizing the worst-case transfer error between the two development runs (min-max transfer).

M7 Mean Transfer minimizes average transfer error across development runs. Comparing M8 directly against M7 tests whether worst-direction regularization provides protection against out-of-run transfer failure.

3. Measured Pilot Limitation Note

Limitation Note: “This three-protein pilot supports further evaluation. Baseline configuration, nested selection/tuning and aggregate uncertainty require correction before claiming method superiority.”

Results apply strictly to same-protein held-out trajectory reconstruction under identical conditions and do not establish zero-shot cross-protein transfer or drug binding.

What is Reconstruction Skill?

Reconstruction skill evaluates whether the selected sensor distances predict held-out target distances better than a development-mean constant baseline: Skill = 1 - (SSE / SSEbaseline).

  • • Zero: Matches the development-mean baseline.
  • • Higher is better: Positive skill indicates meaningful trajectory reconstruction.
  • • Negative values are worse: Indicate worse performance than simply predicting the mean.

What is Retrospective Test-Centered Diagnostic Skill?

A retrospective diagnostic metric computed by centering predictions and targets using the test run's true empirical means: Skillcentered = 1 - (Var(Y - Ŷ) / Var(Y)).

  • • Diagnostic purpose: Isolates dynamic fluctuation tracking from static mean offset recovery.
  • • Positive value: Confirms genuine tracking of trajectory variance.
  • • Retrospective: Uses test means as a post-hoc analytical diagnostic only.

Research Trajectory & Empirical Milestones

Tracing the scientific progression of CHARA from early cancer target inquiries to rigorous trajectory distance reconstruction.

Research Origin Cancer Target Inquiry

1. The Original MD Question

The original research inquiry investigated whether small-molecule compounds could bind cancer-associated proteins (such as c-Myc or mutant p53). The current CHARA study investigates whether a small set of residue-pair distances can reconstruct other distances in an independent simulation run of the same protein.

Current Scope: The current workflow has not answered the original binding question. It establishes quantitative methods for sparse intramolecular distance reconstruction across independent simulation trajectories.

Inquiry Refocused · Distance Reconstruction Evaluated Research Scope Defined
Local Investigation cMYC Monomer Chain E

2. The Local cMYC Reconstruction Lead

Initial exploration of c-Myc monomer chain E yielded a retrospective test-centered diagnostic skill of approximately +0.207, with 63.05% of MSE improvement arising from variance error reduction rather than static mean offset recovery alone.

Simulation Caveats: Detailed audit identified key limitations in the custom simulation setup: coarse-grained topologies, 349 harmonic elastic network restraints, and evaluation strictly restricted to an isolated monomer chain rather than the full simulated heterotetrameric assembly.

Lead Documented · Centered Diagnostic ~+0.207 Simulation Caveats
Completed Pilot ATLAS Atomistic Triplicates

3. The Three-Protein External Pilot

To eliminate custom simulation artifacts, CHARA was evaluated on independent, standardized all-atom simulations from the ATLAS database across 3 structurally distinct proteins: 1utg_A (all-α, skill 0.386), 2cg7_A (all-β, skill 0.319), and 2j6b_A (α+β, skill 0.406).

Pilot Outcome: Across 9 independent held-out runs simulated in explicit solvent CHARMM36m, M8 robust transfer maintained positive reconstruction skill without elastic network restraints or custom force-field modifications.
