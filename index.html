The Problem: Domain Shift

Transcriptomic data varies wildly between sequencing platforms, normalization pipelines, and patient cohorts. A machine learning model trained on TCGA data often fails catastrophically when applied to a local hospital's RNA-seq cohort due to batch effects and distribution shifts.

Traditionally, researchers use Combat or quantile normalization, which requires combining training and testing data, leading to data leakage and destroying the concept of a "frozen" clinical model.

The Solution: Thermodynamic Graphs

Chara solves this by modeling patients as nodes in a Thermodynamic Graph Laplacian. Instead of aligning features blindly, we compute the structural transition probabilities of the new cohort's expression manifold and map them securely into the frozen signature space.

This allows our robust 4,337-gene Cox Proportional Hazards model to execute on unseen data accurately, without ever needing to see the original training set again.
